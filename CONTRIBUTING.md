# Contributing to ARoZENIX PHARMACEUTICALS Website

Thank you for your interest in contributing to the ARoZENIX PHARMACEUTICALS website! This document provides guidelines and instructions for contributing.

## Code of Conduct

Be respectful, professional, and constructive in all interactions.

## How to Contribute

### 1. Reporting Issues
- Check existing issues before creating a new one
- Provide clear, descriptive issue titles
- Include steps to reproduce the problem
- Attach screenshots if relevant

### 2. Submitting Changes
- Fork the repository
- Create a feature branch (`git checkout -b feature/your-feature`)
- Make your changes
- Test thoroughly across devices
- Commit with clear messages
- Push to your fork
- Submit a pull request with detailed description

### 3. Code Style

#### HTML
- Use semantic HTML5 tags
- Keep proper indentation (2 spaces)
- Use descriptive class names
- Add alt text to images

#### CSS
- Follow BEM naming convention
- Group related properties
- Use consistent spacing
- Optimize for mobile-first

#### JavaScript
- Use clear variable names
- Add comments for complex logic
- Follow DRY principle
- Test cross-browser compatibility

### 4. Testing Checklist
- [ ] Responsive design (mobile, tablet, desktop)
- [ ] Cross-browser testing (Chrome, Firefox, Safari, Edge)
- [ ] Form validation
- [ ] Link functionality
- [ ] Accessibility (keyboard navigation, screen readers)
- [ ] Performance (loading times)

### 5. Pull Request Guidelines
- Describe changes clearly
- Reference related issues
- Keep PRs focused and manageable
- Update documentation if needed

## Color Palette Guidelines

When contributing, respect the established color scheme:

- **Primary Blue**: `#0066CC` - Main brand color
- **Emerald Green**: `#00A86B` - Health & growth accent
- **Dark Navy**: `#1a2332` - Text & headlines
- **Light Background**: `#f8fafc` - Clean backgrounds

## Documentation

- Keep README.md updated
- Document new features
- Add inline comments for complex code
- Update CHANGELOG for significant changes

## Questions?

Feel free to open an issue for discussions and questions.

Thank you for contributing! 🙏
