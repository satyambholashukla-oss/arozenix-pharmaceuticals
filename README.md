## 🚀 Getting Started

### Option 1: Direct Browser Access
1. Clone the repository
2. Open `index.html` in any modern web browser
3. Website will load with all features active

### Option 2: GitHub Pages
1. Enable GitHub Pages in repository settings
2. Set source to `main` branch, root folder
3. Access at: `https://satyambholashukla-oss.github.io/arozenix-pharmaceuticals/`

### Option 3: Local Server
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if http-server installed)
http-server
```

Then visit: `http://localhost:8000`

## 🎨 Customization Guide

### Change Company Name
Find and replace `ARoZENIX PHARMACEUTICALS` throughout the file with your company name.

### Update Contact Information
Edit the contact section with your actual:
- Phone number
- Email addresses
- Physical address
- Business hours

### Modify Products
Update the product cards section with your actual pharmaceutical products and descriptions.

### Adjust Colors
Main color variables are in the CSS `/* ================= COLOR PALETTE ================= */` section:
```css
/* Primary: Medical Blue #0066CC */
/* Secondary: Emerald Green #00A86B */
```

### Add Images
Replace emoji icons with actual images by updating:
```html
<div class="product-icon">💊</div>
<!-- To: -->
<img src="path/to/icon.png" alt="Product Icon">
```
